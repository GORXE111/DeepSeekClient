# 宠物素材

三条横向精灵图，每条 4 帧、单帧 64×64、背景透明：

| 文件 | 用途 | 内容 |
|---|---|---|
| `miku-idle.png` | 待机 | 眨眼。**不循环播放** —— 长期停在第 0 帧，偶尔放一次完整四帧，一直眨看着像抽搐。 |
| `miku-call.png` | 等你处理 | 抬手招呼。智能体要审批或有提问时用。 |
| `miku-busy.png` | 忙碌 | 智能体正在跑任务时用。 |

改素材只要替换这三个文件，尺寸和帧数保持一致即可；渲染那边（`../pet-sprite.js`）
按 64×64 × 4 帧读，不需要改代码。
