# 桌面伴侣素材

一个角色一个目录，每条动画一个文件：`<角色>/<动画>.png`。
每条 4 帧、单帧 64×64、背景透明（整张 256×64）。**统一 0.5 秒一帧。**

哪个角色用哪条动画表达什么，全在 [`../pet-characters.js`](../pet-characters.js)。
**这里只放图，语义不在这里。**

## 三条对齐约定

改素材时要一起守住，否则播起来会抖：

- **人物在格子里居中**，按*下半身重心*（自身包围盒底部 40%）对齐。用整体重心会被
  抬起来的手臂拽偏 —— 挥手、欢呼、施法那几帧的手臂在动，腿没动。
- **脚底钉在同一行**，同一角色的所有动画共用（MIKU 是 y=60，庄方宜身量高些是
  y=63）。切换动画时才不会上下跳。
- **alpha 是二值的**（只有 0 和 255）。像素画不要抗锯齿边，半透明像素放大之后是一
  圈灰边。

[`tools/sprites/cut-sheet.py`](../../../tools/sprites/cut-sheet.py) 按这三条切图，
输入支持位图和"每像素一个 `<rect>`"的像素画 SVG：

```sh
.venv-tts/Scripts/python tools/sprites/cut-sheet.py <表文件> <输出目录> "idle,thinking,happy,sad" --feet 60
```

**别按标称网格切。** 画师给的表通常是 256×256 配 4 列，很容易以为格子是 64px。实测
不是：MIKU 那套人物中心在 35 / 96 / 155.5 / 217，而 64 网格该是 32 / 96 / 160 / 224。
按标称网格硬切，每列差两三像素，四列累积成 8px —— 表现为动画一边播一边往左漂，一轮
漂完突然跳回去。竖直方向同理。

切的时候也**不要给裁剪框留余量**：格与格之间往往只隔几个像素，多留 4px 就会把隔壁
人物的边缘吃进来，成品里表现为帧右侧一条竖杠。

### `zhuang/` — 庄方宜（12 条）

`idle` `thinking` `happy` `sad` `wave` `nod` `surprised` `sleepy`
`lightning` `sword` `meditate` `victory`

后四条是角色专属动作（雷法、青霆剑、打坐、报捷）。前三条走"闲时点缀"—— 待机久了偶
尔来一下，比塞进某个固定事件更像她自己在做自己的事；`victory` 则是她的"干完活了"。

角色出自《明日方舟：终末地》，版权属上海鹰角网络科技有限公司。同人二次创作，
**非商业**。本项目若转为商业分发，必须先取得授权，或换掉这套形象。
