# 宠物素材

八条横向精灵图，每条 4 帧、单帧 64×64、背景透明（整张 256×64）。**统一 0.5 秒一帧。**

三条对齐约定，改素材时要一起守住，否则播起来会抖：

- **人物在格子里居中**，按*下半身重心*（自身包围盒底部 40%）对齐。用整体重心会被
  抬起来的手臂拽偏 —— 挥手、欢呼那几帧的手臂在动，腿没动。
- **脚底钉在 y=60**，八条动画共用同一条线。切换动画时才不会上下跳。
- **alpha 是二值的**（只有 0 和 255）。像素画不要抗锯齿边，半透明像素放大之后是一
  圈灰边。

原图是两张 256×256 的 4×4 表，但作者画的格距**不是 64**（实测约 61）：人物中心在
35 / 96 / 155.5 / 217，而 64 网格应该是 32 / 96 / 160 / 224。按标称网格硬切，误差会
累积成"每帧向左漂 2px、一轮漂 8px 然后跳回去"。所以重切要按人物本身对齐，不能按格
子；切的时候也不要给裁剪框留余量 —— 格与格之间只隔几个像素，多留 4px 就会把隔壁人
物的边缘吃进来，成品里表现为帧右侧一条竖杠。

分两类用，但**区别在调用点而不在素材里** —— 同一条动画既能当底色循环，也能插播一轮：

| 文件 | 动画 | 当前用法 |
|---|---|---|
| `miku-idle.png` | 待机 | 默认底色。**没有别的在播时永远是它**，一直循环。 |
| `miku-thinking.png` | 思考 | 底色：智能体正在跑任务。 |
| `miku-wave.png` | 挥手问候 | 底色：等你审批 / 有提问；也插播一轮当出场问候。 |
| `miku-sleepy.png` | 困倦打哈欠 | 底色：待机满 4 分钟没人理。任何互动都叫醒。 |
| `miku-shy.png` | 害羞扭捏 | 底色：正被按住拖动。松手回到拖之前那条。 |
| `miku-happy.png` | 开心 | 插播：宠物自己回答你的时候。 |
| `miku-clap.png` | 拍手庆祝 | 插播：别的智能体干完一轮，她过来报喜。 |
| `miku-sad.png` | 沮丧 | 插播：发送失败。 |

改素材只要替换文件，尺寸、帧数和上面三条对齐约定保持一致即可；渲染那边
（`../pet-sprite.js`）按 64×64 × 4 帧读，不需要改代码。加一条新动画只要在
`pet-sprite.js` 的 `SHEETS` 里登记 —— 节奏是全局的 `FRAME_MS`，不用逐条配。
